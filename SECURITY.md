# Security Policy

## Reporting a Vulnerability

If you discover a security issue, please report it responsibly.

Please avoid opening public GitHub issues for sensitive vulnerabilities.

Instead, contact me directly through:
- GitHub Discussions
- GitHub private security advisories
- or another available contact method listed on my GitHub profile

When reporting an issue, please include:
- description of the vulnerability
- reproduction steps
- potential impact
- proof of concept if applicable

---

## Supported Versions

| Version | Supported |
| ------- | --------- |
| Latest  | Yes |
| Older versions | No |

---

## Scope

Security reports are especially important for:
- markdown rendering
- plugin execution
- code block handling
- encryption/decryption workflows
- XSS-related vulnerabilities
- dependency vulnerabilities
