# Changelog

All notable updates to Opsly MD will be documented here.

---

## Current

### Available
- local-first markdown workspace
- markdown file rendering in browser
- Mermaid diagram support
- math rendering support
- interactive code blocks
- hidden field workflow (secure code)
- document encryption and decryption (passphrase-protected documents)
- table of contents navigation
- responsive reading experience
- browser-based workflow with no account requirement
- VS Code preview extension (`vscode-extension/`)

---
