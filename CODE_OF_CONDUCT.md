# Code of Conduct

## Our Standards

Please be respectful and constructive when participating in this project.

Examples of positive behavior include:
- constructive feedback
- respectful discussions
- helping other contributors
- focusing on technical collaboration

Examples of unacceptable behavior include:
- harassment or abusive language
- personal attacks
- discrimination
- trolling or intentionally disruptive behavior
- publishing private information

---

## Enforcement

Project maintainers reserve the right to remove, edit, or reject comments, commits, issues, and contributions that violate this Code of Conduct.

---

## Scope

This Code of Conduct applies to:
- GitHub issues
- pull requests
- discussions
- project communication spaces
